# panel-label-detection

This check is simply to identify every panel of a given figure. 
The figure is from a scientific publication from a life science journal. These figures are usually separated into panels that are labelled alphabetically starting from A->Z. In the figure caption the panels are usually described and the labelled can be found there as well. 
The aim is to find every panel and its respective label. List every panel label in the figure. Use the caption to confirm panels and their labels. Use the exact label as shown in the paper (e.g. A, (a), 1).

Return only this JSON structure:

{
  "outputs": [
    {"panel_label": "A"},
    {"panel_label": "B"},
    {"panel_label": "C"}
  ]
}
