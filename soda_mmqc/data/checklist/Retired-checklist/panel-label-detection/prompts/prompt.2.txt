# panel-label-detection 

Identify all panel labels in the figure (e.g. A, B, C or (a), (b)). List them in alphabetical order.

 Return JSON:

{
  "outputs": [
    {"panel_label": "A"},
    {"panel_label": "B"},
    {"panel_label": "C"}
  ]
}

Use the exact label as shown in the figure. Include every panel.
