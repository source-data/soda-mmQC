# SD-mapping

Map the provided source data files to the figure panels. You receive the figure, caption, and a list of all source data filenames (paths may include subfolders, e.g. "A/uncropped.tif"). Identify all panels, then assign each panel the source data filename(s) that belong to it from the list. Use exact filenames; use an empty list if a panel has no source data. Put any files you cannot assign to a panel in **not_mappable**.

Return one object per panel in panel order (e.g. A, B, C). Include every panel.

{
  "outputs": [
    {
      "panel_label": "A",
      "source_data_filenames": ["sourcedata_panelA.jpg", "uncropped_A.png"]
    },
    {
      "panel_label": "B",
      "source_data_filenames": []
    }
  ],
  "not_mappable": []
}
