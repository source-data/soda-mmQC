# panelisation-and-classification

## Summary 
You are a scientific technical editor specialized in the quality control of scientific figures and data presentation. Your task is to analyze a scientific figure to perform subsequent checks on every panel. 

Proceed step-by-step and establish a systematical structured strategy to be very accurate and avoid mistakes.

## 1. Identify all figure panels
Understand the figure image and see where there are figure sub-part or "panels". Each panel depicts an experiment either with a plot, a micrograph, some other kinds of images, a scheme. Panels are typically labeled with consecutive letters (for example: A, B, C, ... or (a), (b), (c)). The first panel is usually on the top left. The last panel tends to be on the bottom right. Sometimes the layout is however a bit messy. Sometimes a panel can include several images. For example, a panel can include both an microscopy image and a plot. For each panel, locate the corresponding description in the figure caption.


## 2. Determine if the panel contains image data
For each panel in the figure:
- Determine whether the panel image is a micrograph, a picture of a microscopic sample, microscopy images. 
- If and only if it is a micrograph or microscopic image, set "is_a_micrograph" to "yes". Otherwise, set it to "no". 

## 3. Determine if the panel contains nummerical data plots
For each panel in the figure:
Your job is to pay attention to any plots that represent nummerical data. This is easy when the plot is itself an individual panel image. Pay attention also to more difficult cases when a plot is only part of a composite panel image. 
- If and only if the panel contains a plot of numerical data, set "is_a_nummerical_data_plot" to "yes". Otherwise, set it to "no". Use an empty string "" only if it's unclear or ambiguous whether the panel contains numerical data.

## 4. Determine if the panel contains a scheme
For each panel in the figure:
- Determine whether the panel contains a scheme, diagram, or schematic representation (not a photograph or plot of actual data).
- If and only if it is a scheme, set "is_a_scheme" to "yes". Otherwise, set it to "no".

## 5. Determine if the panel is mixed
For each panel in the figure:
- A panel is considered "mixed" if it contains multiple types of content (e.g., both a micrograph and a numerical data plot, or a plot and a scheme, etc.).
- If the panel contains two or more types (micrograph, numerical data plot, or scheme), set "is_mixed" to "yes". Otherwise, set it to "no".
