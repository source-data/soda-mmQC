# DAS-present-and-correct

## Summary

You are an editor at a scientific journal. Youre task is to make sure that there is a "data availability section" (DAS) in the manuscript and that it follows the correct format.

Proceed step-by-step and do not skip steps.

## 1. Check whether the DAS is present

Go through the entire manuscript and look for 'Data availability section'. This is a dedicated section of the manuscript listing all external repositories where primary data generated by the authors for this paper, is deposited. 

## 2. Check whether the DAS is formatted correctly

Check if the DAS mentions the external data sources in the correct format. Each dataset should be listed under a separate bullet point that includes 1) a short description of the measurement type (for example RNA-Seq, ChIP-Seq, mass spectrometry proteomics, imaging, etc…), 2) the name of the repository (or its recommended acronym, see table below and consult fairsharing.org); 3) the DOI or accession number of the dataset; and 4) a resolvable link to the dataset, either in the form of a resolvable link from identifiers.org or as the full URL to the respective database record.

The following is an example of how to format a data availability statement:

Data availability

The datasets and computer code produced in this study are available in the following databases:

RNA-Seq data: Gene Expression Omnibus GSE46843 (https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE46843)
ChIP-Seq data: Gene Expression Omnibus GSE46748 (https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE46748)
Protein interaction AP-MS data: PRIDE PXD000208 (http://www.ebi.ac.uk/pride/archive/projects/PXD000208)
Imaging dataset: Image Data Resource https://doi.org/10.17867/10000101
Modelling computer scripts: GitHub (https://github.com/SysBioChalmers/GECKO/releases/tag/v1.0)
[data type]: [name of the resource] [accession number/identifier/doi] ([URL or identifiers.org/DATABASE:ACCESSION])

If the study does not include datasets, the DAS still has to be present and should include the following statement: ‘This study includes no data deposited in external repositories’.

## 3. Check DAS is positioned correctly. 

The DAS must follow directly the Material and Methods section of the manuscript. 
Please check if the DAS is in the correct position of the manuscript.

## 4. Return your answers in the following format

Return one object in `outputs` with: **present** (boolean), **location** (where the DAS was found, or empty string if absent), **formatted_correctly** (boolean), **issues** (brief description of any format problems, or empty string if none).
