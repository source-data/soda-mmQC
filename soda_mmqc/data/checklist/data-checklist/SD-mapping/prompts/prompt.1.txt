# SD-mapping

## Summary
You are a scientific technical editor. Your task is to **map the provided source data files** to the **panels** of the figure. The source data is stored in a folder named **source_data**, in the same path as the figure image and the caption. You do not need to open any files—you will receive a **list of all file names** in the source_data folder (and subfolders). Use this list to map each panel to the relevant file(s) by name. File type does not matter (images, spreadsheets, PDFs, etc.). For each figure panel, list which source data file(s), if any, correspond to that panel.

Proceed step-by-step and be systematic.

## 1. Identify all figure panels
Understand the figure image and see where there are figure sub-part or "panels". Each panel depicts an experiment either with a plot, a micrograph, some other kinds of images, a scheme. Panels are typically labeled with consecutive letters (for example: A, B, C, ... or (a), (b), (c)). The first panel is usually on the top left. The last panel tends to be on the bottom right. Sometimes the layout is however a bit messy. Sometimes a panel can include several images. For example, a panel can include both an microscopy image and a plot. For each panel, locate the corresponding description in the figure caption.

## 2. Review the source data file names
You will receive the **full list of file names** in the source_data folder (same path as the figure and caption). Paths may include subfolders (e.g. "A/uncropped.tif", "panel_B/data.xlsx"). Source data files can be any type: image files (.jpg, .png, .tif), tabular data (.xlsx, .csv), PDFs, etc. Use this list to see which files exist; filenames and folder names (e.g. '1a', 'Fig2B', 'A', 'B') often indicate which panel they belong to. 

## 3. Map source data to panels
For each panel in the figure, determine which source data file(s) from the list correspond to that panel. A source data file may apply to one panel, several panels, or none. Use the exact file name or path as shown in the source_data file list (e.g. "A/uncropped.tif" or "Western blot - 1C.tif"). If a panel has no corresponding source data, leave the list empty. If there are source data files that are not mappable to any panel, include their file name (or path) in **not_mappable**.

## 4. Return your mapping in the following JSON format

Provide one object per figure panel, in panel order (e.g. A, B, C). Include every panel, even if it has no source data.

{
  "outputs": [
    {
      "panel_label": "A",
      "source_data_filenames": ["sourcedata_panelA.jpg", "uncropped_A.png"]
    },
    {
      "panel_label": "B",
      "source_data_filenames": []
    }
  ],
  "not_mappable": ["unidentified_file.xlsx"]
}

- **panel_label**: The panel label as shown in the figure.
- **source_data_filenames**: List of filenames of source data files that correspond to this panel. Use the exact filename as provided. Empty list if no source data applies to this panel.
- **not_mappable**: List of source data filenames that could not be assigned to any panel. Empty array if all files are mappable.
